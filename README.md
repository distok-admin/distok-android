# Distok për Android

Ky depo mban vetëm skedarët e aplikacionit Distok për Android (APK), për shkarkim. Kodi burimor nuk është këtu.

- Shkarkoni aplikacionin nga faqja zyrtare: **https://distok.app/downloads**
- Çdo version është një "release" më vete. Versionet `staging-…` janë versione prove dhe nuk janë për dyqanet.
- Gjurma SHA-256 e certifikatës së nënshkrimit të Distok:

  `F0:E5:32:15:BE:DD:BD:C1:2D:19:BD:CF:DB:EA:C5:E7:C6:C8:D1:57:1F:96:C4:4B:75:BF:8B:95:57:94:ED:84`

  Kontrolloni një skedar me komandën: `apksigner verify --print-certs distok-<versioni>.apk`

# Distok for Android

This repository holds only the Distok Android app files (APK), for download. There is no source code here.

- Download the app from the official page: **https://distok.app/downloads**
- Each version is its own release. `staging-…` versions are test builds and are not for shops.
- SHA-256 fingerprint of Distok's signing certificate:

  `F0:E5:32:15:BE:DD:BD:C1:2D:19:BD:CF:DB:EA:C5:E7:C6:C8:D1:57:1F:96:C4:4B:75:BF:8B:95:57:94:ED:84`

  Check a file with: `apksigner verify --print-certs distok-<version>.apk`
